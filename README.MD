Prática – Persistência de Dados com JPA e Hibernate
📖 Sobre o projeto

Este repositório contém a implementação de uma atividade prática da disciplina de Programação Web I, cujo objetivo foi aplicar os conceitos de persistência de dados utilizando JPA (Jakarta Persistence API) e Hibernate.

Durante a atividade foi desenvolvida uma aplicação Java capaz de realizar operações de persistência em banco de dados através do padrão DAO (Data Access Object), utilizando o EntityManager para gerenciar entidades e transações.

O projeto tem caráter didático, servindo como apoio ao aprendizado da camada de persistência em aplicações Java.

🎯 Objetivos da prática
Compreender o funcionamento da JPA;
Configurar o Hibernate como implementação da JPA;
Criar entidades utilizando anotações (@Entity, @Id, @Column, etc.);
Configurar a unidade de persistência através do arquivo persistence.xml;
Implementar operações de CRUD utilizando o padrão DAO;
Utilizar o EntityManager para gerenciamento das transações;
Organizar o projeto seguindo boas práticas de separação de responsabilidades.
🛠️ Tecnologias utilizadas
Java
Jakarta Persistence (JPA)
Hibernate ORM
Maven
MySQL
JDBC
IDE IntelliJ IDEA
